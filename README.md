# Fortune Cookie for the Liquidated Trader

A one-line fortune cookie for the crypto trader who just got liquidated: small, oracular, and warm enough to laugh at the loss instead of crying over it. The program writes the fortune as a single UTF-8 line to `entry.txt`.
